# Product

## Register

product

## Users

Rim, a solo developer, orchestrating multiple AI coding agents (Claude Code, Codex, Gemini) at night on one Windows machine, for hours at a stretch. Hands often off the keyboard: the primary input is voice. The job: launch agents, hand them tasks, watch their progress, hear when they finish.

## Product Purpose

Agent Launcher is an agent development environment. A local model (the orchestrator) is the main interface: it launches named agents, routes prompts to them, watches what they do, summarizes output, opens browser previews, and moves between workspaces. Success: Rim can run a whole agent team without touching a terminal by hand.

## Brand Personality

Calm, capable, nocturnal. The tool disappears into the task; status is glanceable from across the room. Confidence without noise.

## Anti-references

- Generic Electron dev-tool gray (the previous version of this very app).
- The CNVS pixel-art look copied literally: the inspiration is its calm night canvas and floating command bar, not its sprite art.
- Dashboard slop: hero metrics, identical card grids, decorative gradients.

## Design Principles

1. Status over chrome: every agent's state readable in one glance, from a distance.
2. Voice first, keyboard always: everything the orchestrator does has a visible, clickable equivalent.
3. Night shift: dark, low-stimulation surfaces tuned for long sessions in a dark room.
4. One accent, earned: orange marks attention (working, active, primary action) and nothing else.
5. No dashes in visible UI copy.

## Accessibility & Inclusion

Contrast at or above 4.5:1 for body text. Reduced motion honored for every animation. All interactive elements keyboard reachable.
